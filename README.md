# 可视化字体管理 / Visual Font Manager

在 **DSH 0.2.1 系列（含预发布版）** 的「插件 → 可视化字体管理」详情页内提供字体设置和效果预览。保留内置「设置 → 通用 → 字体」界面、主题和其他设置不变；两处共享同一份内置字体配置。

当前版本：**1.2.1**。

## 使用

新版将用途切换、字体选择与字号集中在紧凑编辑栏，默认并排显示当前与修改后效果；宽屏编辑栏及底部应用区在插件内容范围内保持可见。颜色、边框和强调色跟随 DSH 当前主题，预览保留原生字号比例。

打开 **插件 → 可视化字体管理**，在「字体设置与预览」选择「正文与界面」「代码」或「终端」，预览场景随用途切换。点击字体选择器展开浮层，可搜索推荐候选或授权读取完整本机字体列表；浮层不会推走预览。字号支持滑块、加减与文本输入，允许清空后逐字输入，无效输入会阻止应用。高级选项提供字体回退顺序；点击“完成”后更新预览，输入逗号不会被提前还原。默认 100% 为实际字号，150% 只放大预览，不改变实际应用字号。

**所有改动先预览，只有「应用更改」才持久化。** 底栏列出每个用途的字体与字号差异；一次原子应用合并全部修改，同步到同一 profile 的所有会话和连接。切换页面后，已暂存的草稿在同一浏览器插件实例的内存中保留；刷新、关闭或卸载插件会清空，浏览器允许时会提示未保存修改。撤销全部、冲突后的重新载入都需要确认。「恢复当前用途的继承值」先预览，应用后才移除覆盖；恢复后单独编辑字号或字体不会取消另一个字段的继承。外部设置变化会阻止旧草稿覆盖。

| 用途 | 字号范围 | 默认字号 |
| --- | --- | --- |
| 正文与界面 | 10–22 px | 14 px |
| 代码 | 10–16 px | 11 px |
| 终端 | 10–20 px | 13 px |

字体库中的候选名称不代表已安装。浏览器会为缺失字体、缺失字形选择回退字体。「读取本机字体」通过浏览器 Local Font Access API 请求权限，只枚举浏览器所在设备；字体名称留在当前页面内存，不上传、不写入 profile，不读取字体文件。不支持该 API 的浏览器仍能手动输入名称和预览。插件不下载、安装或分发字体。

并排对比将「当前已应用」与「修改后」放在相同宽度中，保留两侧真实的三类字体和字号；也可切换为仅看修改后。窄窗口上下排列，修改后的预览在前，不缩小字体。「预览内容与字形」对话框可替换当前场景正文、代码或终端输出，查看易混字符与规范化字体栈。

对话预览包含用户消息气泡、助手 Markdown 标题/段落/列表/表格/行内代码，以及带模型栏的输入区；代码场景包含代码块、Bash 调用行和工具输出；终端场景包含标签栏与命令输出。正文、代码、终端分别使用各自设置，固定字号的界面栏不会被代码字号错误放大。

这些都是本插件内的只读示例，不读取真实会话，不发送消息，不运行命令。排版比例依据 DSH 0.2.1-rc.2 发布产物，颜色跟随当前主题；代码样本使用中性文字与注释色，不载入完整 Shiki。终端不是 xterm 实例，使用浏览器自然行框近似显示，真实终端的测量格宽、格高、宽字符与光标渲染仍可能不同。

## 构建与安装

零第三方构建依赖，不运行安装脚本。

开发命令：

~~~sh
npm run build
npm test
npm run check

# 可选：隔离安装真实 React/Chrome 组件回归依赖（不进入插件分发）
npm install --prefix .ui-test --no-save --package-lock=false --ignore-scripts react@19.2.0 react-dom@19.2.0 esbuild@0.25.11
npm run test:browser
~~~

当前安装目录为 `~/.dsh-local-plugins/dsh-fonts-manager`，开发副本另行保留。通过 DSH 的插件管理安装这个目录；本地安装会保留路径引用，不要移动或删除正在使用的安装目录。发布用包包含预构建浏览器产物，可先执行 `npm pack --dry-run` 核对分发文件。按用户要求，`engines.dsh` 为 `>=0.2.1-0 <0.2.2-0`，覆盖 0.2.1 的预发布版与正式版，不包含 0.2.2。实现基线仍是 rc.2；rc.3 已完成源码差异和目标注册接口的隔离检查，未完成整套 rc.3 浏览器验收，范围内其他版本未逐一验证。仅浏览器实现更新且 Host/依赖声明不变时，构建后发布到固定安装目录，由现有 Host 的 client bundle 监听更新 revision；插件卡片版本信息可通过“刷新”或整页刷新重新读取，无需移除并重装。

## 实现与安全边界

界面只注册 `plugins.bundle.config`，key 为包名 `@local/dsh-fonts-manager`；直接嵌入本插件详情页的说明和组件列表之间。不增加侧栏页面，不覆盖任何既有字体设置 slot。详情页的标题、图标、导航和滚动由 DSH 插件管理器负责。Client 通过公开的 `ctx.configForms` 获取 `ui-theme` 快照，并通过原生 `mutate(ops, expectedRevision)` 提交六个字体字段的原子修改；不直接写 profile 文件、不覆盖主题 preference，也不对全局 DOM 注入预览样式。颜色使用 DSH 主题 tokens，页面文字和包元数据提供中英文。

Agent 工具 `font_manager` 提供 `read`、`apply`、`reset`，与 UI 共享字体规范化和原生 Host 设置操作。先 read 获取 revision，再 apply/reset；写操作遵循 danger-full-access 权限门禁，不为其他工具放宽权限。`reset` 恢复继承值，空字体字符串则显式选择内置字体栈，两者语义不同。
